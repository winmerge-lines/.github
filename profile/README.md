# WinMerge - See the Difference Before You Copy

## Lock

Two paths you can open.
You know which one is the source of truth, if one of them is.
The folders are not so huge that you needed a filter. Start with a small pair.
You are not comparing a system directory to a random backup "to clean Windows."

## Key

Point the left side at one folder and the right at the other.
Run the compare.
Read a file that is marked different.
Open that difference and see the actual lines or the size. Do not copy yet.

## What goes in

Project folders you own.
Two exports of the same notes.
A backup and the original, when you are checking that the backup is complete.
Filters that hide build junk you already understand, so the list is about your files.

## What stays out

Someone else's home directory.
A binary you do not need to diff. Identical size and time may be enough. A hex dump of an executable you do not own is not the task.
An automatic mirror. This window is a look.
Passwords sitting in a config you are about to paste into a chat as a "diff."

![WinMerge comparing two folders the user owns, with one different file opened](https://www.progress.com/images/default-source/ipsblogposts/image-jul-10-2020-06-17-14-27-pm.jpg)

## Turn

Decide file by file, or decide that the whole side is the good one.
Copy only in the direction you named.
After a copy, compare again. The list should shrink.
If a file is only on the backup, it may be the one you deleted on purpose. Do not copy it back until you recognize it.

## Check

The destination now has the version you chose.
The other side still has what you meant to keep.
A second compare is quiet.
Explorer shows the same sizes on a file you opened.

## Leave

Window closed.
No half-applied copy.
Filters noted if you will reuse them.
The folders still make sense without WinMerge open.

## Spare

The compare does not replace a backup. If both folders are wrong, the diff is a diff of two mistakes.
A third copy on another disk is the spare.
Do not delete the older side the same hour if you are unsure.
A screenshot of the result is enough to ask someone. Do not send them the files if they should not have them.

## Not this lock

A sync tool copies on a schedule. This compares when you ask.
A hash tells you a file matches a published string. A diff tells you how two copies differ.
This will not merge a legal document into a single truth by magic. You still read it.
A cloud app may already be changing one side while you compare. Pause that if you need a stable picture.
Someone else's repository is not a folder you overwrite.

## Next visit

The same two paths if the job continues.
New day, confirm which side is current before you copy.
After an update of WinMerge, compare one known pair.
Do not save a filter that hides the files you actually needed. A quiet list can be a hidden difference.

## Hand back

Close the compare before you leave a shared PC.
Do not leave a project path visible if the next person should not see it.
Uninstall leaves both folders. The last copy you made stays.
A wrong overwrite is undone from the side you did not touch, if you still have it.

## Seal

You can say which side won.
The other side is intact or updated on purpose.
No system folder was in the compare.
The window is not still set to copy on the next click.

## Vault line

winmerge folder list, line diff, filter off, left and right panes, patch file, compare again, which side wins, own copies
